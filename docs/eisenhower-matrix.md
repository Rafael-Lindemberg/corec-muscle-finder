# Eisenhower Matrix

## Do - Your MVP

- Select a target muscle group.
- Show matching machines with summaries and CoRec locations.
- Click a machine to see exercises for the selected muscle.

## Schedule - V2 and Later

- Add a clickable body diagram for muscle selection.
- Add exercise pictures and more detailed instructions.
- Add a visual gym map of machine locations.
- Explore a phone-friendly version.

## Delegate - Use a Library

- Use JavaFX controls and layouts for the interface.
- Use Gson to parse the JSON data.
- Use Java standard file utilities to read local data.

## Delete - Cut It

- Automatic live machine occupancy detection.
- Favorites, workout logging, and equipment availability filters.
- Social profiles, followers, and workout sharing.
- AI-generated personalized workout plans.
- Payments and subscription features.
